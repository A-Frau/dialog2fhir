# dialog2fhir

Extract structured FHIR resources from German doctor–patient dialogs using LLMs,
and evaluate how well different approaches perform.

**Status:** work in progress (v0.1 in development)

## Planned
- v0.1 LLM extraction to validated FHIR JSON
- v0.2 Evaluation on synthetic German dialogs
- v0.3 Model comparison (API vs. local, zero-shot vs. RAG)
- v0.4 Speech input (Whisper)
- v1.0 Demo, Docker, CI
